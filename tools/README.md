# tools

| ファイル | 役割 |
|---|---|
| `jra_pdf.py` | JRA公式の成績PDF（1開催日・1場）→ レースと全出走馬の数字。2段組・埋め込みフォントの数字・通過順位の「・」印・太字の重ね打ちに対応 |
| `collect_results.py` | 成績PDFを集めて `data/results/<年>/<場>_{races,runs}.csv.gz` に保存（差分方式、PDF本体は保存しない） |
| `redo.txt` | 読み取りを直したあとに取り直す開催日の一覧（ふだんは空） |
| `keiba_sim.py` | レースシミュレーション本体（`builddb` / `list` / `sim` / `backtest` / `validate`）。`builddb` は出馬表と `data/results` の両方を読む |
| `race_video.py` | シミュレーション1回分のレース動画（mp4・gif） |

## data/results の中身（2021年1月〜、全10場）

- `index.csv`：取得済みの開催日（1,693日・20,305レース・279,433頭 ／ 2026-11-15時点）
- `<年>/<場>_races.csv.gz`：1レース1行。日付・場・回・日・R・レース名・格・クラス・芝ダ障・距離・内外・回り・天候・馬場・頭数・ハロンタイム・前後半3F・上がり4F
- `<年>/<場>_runs.csv.gz`：1頭1行。着順・状態（取消/除外/中止/降着）・枠・馬番・性齢・斤量・騎手・馬体重と増減・タイム・単勝オッズ・人気・各コーナーの通過順

## 検算

- 出馬表の近4走データと照合できた2,464頭で、着順・タイム・斤量・馬体重・通過順が全件一致
- ハロンタイムの合計＝勝ちタイム：99.94%（19,574レース中、不一致11）
- PDFの集計ページに書かれた「競走回数」と読めたレース数を毎回照合（食い違えばログに「要確認」と出る）
- 12レースに届かない日は5日あり、いずれもPDFの集計ページに書かれた実施レース数と一致（競走の取りやめ。うち3日は「競走の中止」の記載も確認）

## 分かっている欠け・注意

- 2023年8月20日 札幌7R・8R（クローバー賞）は、PDFのそのページだけ数字が図形として描かれていて読めない（全体の0.01%）
- 人気は単勝オッズの順で付けている（同オッズの馬どうしは実際の人気順と入れ替わることがある：0.85%）
- 1頭ごとの上がり3FはPDFに無いので入っていない（レース全体の上がり3Fはある）
- 馬名が10文字以上の馬は外国馬（例：ロマンチックウォリアー）
- 地方・海外のレースは含まない

## シミュレーションの検証（`validate`）

成績データの全レースを「その週より前のデータだけ」で予想して採点する。2025年1月〜2026年11月14日の平地・新馬以外 5,706レース：

| | ◎（SIM本命）の勝率 | ◎の3着内 | ◎の単勝回収 | 対数損失 |
|---|---|---|---|---|
| 新しいエンジン（2026-11-15） | 28.7% | 60.5% | 80% | 2.091 |
| それまでのエンジン | 26.8% | 57.2% | 80% | 2.215 |
| 1番人気（確定オッズ） | 33.3% | 65.1% | 79% | 1.935 |

市場（オッズ）のほうが精度は高い。SIMの勝率そのものは実際の勝率とよく合っている（20%台と出した馬は22%、40%以上と出した馬は46%勝つ）。
