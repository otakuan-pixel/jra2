# tools

| ファイル | 役割 |
|---|---|
| `jra_pdf.py` | JRA公式の成績PDF（1開催日・1場）→ レースと全出走馬の数字。2段組・埋め込みフォントの数字・通過順位の「・」印に対応 |
| `collect_results.py` | 成績PDFを集めて `data/results/<年>/<場>_{races,runs}.csv.gz` に保存（差分方式、PDF本体は保存しない） |
| `keiba_sim.py` | レースシミュレーション本体（`builddb` / `list` / `sim` / `backtest`） |
| `race_video.py` | シミュレーション1回分のレース動画（mp4・gif） |

`data/results/` の検算（中山・阪神 2021〜2026年、470日・5,640レース・78,051頭）
- 出馬表の近4走データと照合できた2,464頭で、着順・タイム・斤量・馬体重・通過順が全件一致
- ハロンタイムの合計＝勝ちタイム：99.91%
- 人気は単勝オッズの順で付けている（同オッズの馬どうしは実際の人気順と入れ替わることがある：0.85%）
- 1頭ごとの上がり3FはPDFに無いので入っていない
