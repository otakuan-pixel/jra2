# tools

| ファイル | 役割 |
|---|---|
| `jra_pdf.py` | JRA公式の成績PDF（1開催日・1場）→ レースと全出走馬の数字。2段組・埋め込みフォントの数字・通過順位の「・」印・太字の重ね打ちに対応 |
| `collect_results.py` | 成績PDFを集めて `data/results/<年>/<場>_{races,runs}.csv.gz` に保存（差分方式、PDF本体は保存しない） |
| `redo.txt` | 読み取りを直したあとに取り直す開催日の一覧（ふだんは空。取り直せた分は自動で外れる） |
| `keiba_sim.py` | レースシミュレーション本体（`builddb` / `list` / `sim` / `backtest` / `validate`）。`builddb` は出馬表と `data/results` の両方を読む |
| `race_video.py` | シミュレーション1回分のレース動画（mp4・gif） |

## data/results の中身（2021年1月〜、全10場）

- `index.csv`：取得済みの開催日（1,693日・20,305レース・279,433頭 ／ 2026-11-15時点）
- `<年>/<場>_races.csv.gz`：1レース1行。日付・場・回・日・R・レース名・格・クラス・芝ダ障・距離・内外・回り・天候・馬場・頭数・ハロンタイム・前後半3F・上がり4F
- `<年>/<場>_runs.csv.gz`：1頭1行。着順・状態（取消/除外/中止/降着）・枠・馬番・性齢・斤量・騎手・馬体重と増減・タイム・単勝オッズ・人気・各コーナーの通過順・調教師・ブリンカー（B）・馬主・生産者（2026-11-17追加。馬主と生産者は折り返しのある欄をそのままつないだ文字列で、同じ牧場でも書き方が2通りになることがある）

## 検算

- 出馬表の近4走データと照合できた2,464頭で、着順・タイム・斤量・馬体重・通過順が全件一致
- ハロンタイムの合計＝勝ちタイム：99.94%（19,574レース中、不一致11）
- PDFの集計ページに書かれた「競走回数」と読めたレース数を毎回照合（食い違えばログに「要確認」と出る）
- 12レースに届かない日は5日あり、いずれもPDFの集計ページに書かれた実施レース数と一致（競走の取りやめ。うち3日は「競走の中止」の記載も確認）

## 分かっている欠け・注意

- 2023年8月20日 札幌7R・8R（クローバー賞）は、PDFのそのページだけ数字が図形として描かれていて読めない（全体の0.01%）
- 人気は単勝オッズの順で付けている（同オッズの馬どうしは実際の人気順と入れ替わることがある：0.85%）
- 1頭ごとの上がり3FはPDFに無いので入っていない（レース全体の上がり3Fはある）
- 馬名が10文字以上の馬は外国馬（例：ロマンチックウォリアー）
- 地方・海外のレースは含まない

## シミュレーションの検証（`validate`）

成績データの全レースを「その週より前のデータだけ」で予想して採点する。2025年1月〜2026年11月15日の平地・新馬以外 5,735レース：

| | ◎（SIM本命）の勝率 | ◎の3着内 | ◎の単勝回収 | 対数損失 |
|---|---|---|---|---|
| 第4版（2026-11-17） | 30.2% | 61.8% | 80% | 2.046 |
| 第3版（2026-11-15。5,706レース） | 28.7% | 60.5% | 80% | 2.091 |
| 1番人気（確定オッズ） | 33.3% | 65.2% | 79% | 1.935 |

第4版は、第3版で見込みと実際がずれていた条件（騎手の勝率、馬体重、前走の着順、クラスの上げ下げ、間隔、コース適性、枠、脚質、キャリアの浅い馬の調教師）を補正したもの。
市場（オッズ）のほうが精度は高く、SIMと市場の評価が割れたときは市場のほうが当たっている。SIMの勝率そのものは実際の勝率とよく合う（20%台前半と出した馬は24%、40%以上と出した馬は47%勝つ）。

## オッズ込みの期待値（検証中。`sim --odds`）

`sim` に発走前の単勝オッズを渡すと（`--odds "1:4.4,2:12.3,…" --odds-asof "11/22 14:50"`）、オッズから見た勝率にSIMの能力値と「市場が見誤りやすい向き」を足して勝率を作り直し、期待値（勝率×オッズ）を出す。★＝1.0以上、☆＝0.9以上（どちらも50倍未満のみ）。

- 四半期ごとの入れ替え検証（5,735レース、確定オッズ）：★の単勝回収率102%（誤差の幅72〜137%）、☆以上で97%（86〜108%）。全馬を買うと約80%
- 条件（オッズ帯・クラス・競馬場・前走の不利など）で絞る方法は、両年とも100%を超えるものが無かった
- **前日のオッズで選ぶと効かない**：当日朝より前のオッズで☆以上を選び確定オッズで払い戻すと87%（230レース・290点）。選ばれた馬は締切までにオッズが下がる（中央値で0.93倍）。発走直前のオッズで判定すること
- 期待値0.8未満・10倍未満の馬（割高）は、前日オッズで選んでも回収率55%。避ける目安になる
