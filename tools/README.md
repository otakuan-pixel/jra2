# tools

| ファイル | 役割 |
|---|---|
| `jra_pdf.py` | JRA公式の成績PDF（1開催日・1場）→ レースと全出走馬の数字。2段組・埋め込みフォントの数字・通過順位の「・」印・太字の重ね打ちに対応 |
| `collect_results.py` | 成績PDFを集めて `data/results/<年>/<場>_{races,runs}.csv.gz` に保存（差分方式、PDF本体は保存しない） |
| `redo.txt` | 読み取りを直したあとに取り直す開催日の一覧（ふだんは空。取り直せた分は自動で外れる） |
| `keiba_sim.py` | レースシミュレーション本体（`builddb` / `list` / `sim` / `backtest` / `validate`）。`builddb` は出馬表と `data/results` の両方を読む |
| `race_video.py` | シミュレーション1回分のレース動画（mp4・gif） |

## data/results の中身（2021年1月〜、全10場）

- `index.csv`：取得済みの開催日（1,693日・20,305レース・279,433頭 ／ 2026-11-15時点）
- `<年>/<場>_races.csv.gz`：1レース1行。日付・場・回・日・R・レース名・格・クラス・芝ダ障・距離・内外・回り・天候・馬場・頭数・ハロンタイム・前後半3F・上がり4F
- `<年>/<場>_runs.csv.gz`：1頭1行。着順・状態（取消/除外/中止/降着）・枠・馬番・性齢・斤量・騎手・馬体重と増減・タイム・単勝オッズ・人気・各コーナーの通過順・調教師・ブリンカー（B）・馬主・生産者（2026-11-17追加。馬主と生産者は折り返しのある欄をそのままつないだ文字列で、同じ牧場でも書き方が2通りになることがある）

## 検算

- 出馬表の近4走データと照合できた2,464頭で、着順・タイム・斤量・馬体重・通過順が全件一致
- ハロンタイムの合計＝勝ちタイム：99.94%（19,574レース中、不一致11）
- PDFの集計ページに書かれた「競走回数」と読めたレース数を毎回照合（食い違えばログに「要確認」と出る）
- 12レースに届かない日は5日あり、いずれもPDFの集計ページに書かれた実施レース数と一致（競走の取りやめ。うち3日は「競走の中止」の記載も確認）

## 分かっている欠け・注意

- 2023年8月20日 札幌7R・8R（クローバー賞）は、PDFのそのページだけ数字が図形として描かれていて読めない（全体の0.01%）
- 人気は単勝オッズの順で付けている（同オッズの馬どうしは実際の人気順と入れ替わることがある：0.85%）
- 1頭ごとの上がり3FはPDFに無いので入っていない（レース全体の上がり3Fはある）
- 馬名が10文字以上の馬は外国馬（例：ロマンチックウォリアー）
- 地方・海外のレースは含まない

## シミュレーションの検証（`validate`）

成績データの全レースを「その週より前のデータだけ」で予想して採点する。2025年1月〜2026年11月15日の平地・新馬以外 5,735レース：

| | ◎（SIM本命）の勝率 | ◎の3着内 | ◎の単勝回収 | 対数損失 |
|---|---|---|---|---|
| 第5版（2026-11-18） | 30.2% | 61.9% | 80% | 2.044 |
| 第4版（2026-11-17） | 30.2% | 61.8% | 80% | 2.046 |
| 第3版（2026-11-15。5,706レース） | 28.7% | 60.5% | 80% | 2.091 |
| 1番人気（確定オッズ） | 33.3% | 65.2% | 79% | 1.935 |

第4版は、第3版で見込みと実際がずれていた条件（騎手の勝率、馬体重、前走の着順、クラスの上げ下げ、間隔、コース適性、枠、脚質、キャリアの浅い馬の調教師）を補正したもの。
市場（オッズ）のほうが精度は高く、SIMと市場の評価が割れたときは市場のほうが当たっている。SIMの勝率そのものは実際の勝率とよく合う（20%台前半と出した馬は24%、40%以上と出した馬は47%勝つ）。

第5版は指数の作り方を見直した（時計の反映 0.3→0.5、スローの割り戻し 0.35→0.7、レースレベルの寄せ方 4→2、過去走の人気 0.7→0.4、少ない出走数の寄せ方 0.3→0.15）。
2024年の全レースで約40通りを比べて決め、2025〜26年は決めるのに使っていない。SIM単独の伸びは小さい（対数損失 2.046→2.044）。
大きく変わったのはオッズ込みの期待値のほう（下）。

## オッズ込みの期待値（検証中。`sim --odds`）

`sim` に発走前の単勝オッズを渡すと（`--odds "1:4.4,2:12.3,…" --odds-asof "11/22 14:50"`）、オッズから見た勝率に、SIMの能力値と「市場が見誤りやすい向き」を足して勝率を作り直し、期待値（勝率×オッズ）を出す。★＝1.0以上、☆＝0.9以上（どちらも50倍未満のみ）。

第5版（2026-11-18）で16項目にした：

- **時計重視の能力値 mu_t**：時計をそのまま使い（w_resid=1.0）、過去走の人気は使わない。SIMの能力値とは別に作る。市場は相手関係はよく織り込んでいるが、時計は織り込みきっていない。2024年の検証では、市場に足せる情報が第4版の能力値の約4倍あった
- 通算3着内率・前走着順の補正量（成績の良い馬・前走好走馬は買われすぎ）
- コースごとの枠の有利不利（市場は織り込みきっていない）
- 生産者が市場の見立てより勝っている度合い（直近2年）
- 第4版の項目（騎手・調教師の勝率、追込、前走より下のクラス、過去走1走、古馬と走る3歳、連闘・中1週、前走6着以下）

**検証は「その四半期より前のデータだけ」で係数を推定する通し方式に変えた。** 第4版の数字は、係数を推定した期間と同じ期間で採点していたので良く見えていた。2025〜26年の5,728レースでの比較：

| | 対数損失 | 市場より良い確率 |
|---|---|---|
| 市場（確定オッズ） | 1.9338 | — |
| 第4版の11項目（通しで推定し直し） | 1.9305 | — |
| **第5版の16項目** | **1.9275** | 100%（改善幅0.0063、95%の幅 0.0030〜0.0096） |

第5版は第4版の11項目より良い（改善幅0.0018、95%の幅 0.0001〜0.0034）。

単勝の回収率（第5版・通し方式・確定オッズ。カッコは95%の幅）：

- ★（期待値1.0以上・50倍未満）：1,207点、94%（76〜113%）
- ☆以上（0.9以上・50倍未満）：6,496点、92%（84〜100%）
- 1.1以上・50倍未満：207点、148%（95〜208%）。点数が少なく、後から見つけた区切りなので参考
- 割高（0.8未満・10倍未満）：12,135点、71%

確率の精度は市場より確かに上がったが、**単勝で100%を超えるとは言えない**。発走前のオッズで買う実戦では、これより下がる。
**前日のオッズで選ぶと効かない**（第4版の検証）：当日朝より前のオッズで☆以上を選び確定オッズで払い戻すと87%。選ばれた馬は締切までにオッズが下がる（中央値で0.93倍）。発走直前のオッズで判定すること。

検証のスクリプトと結果は `otakuan-pixel/-jra-data` の `analysis/`。

## 5頭推奨（◎○▲△△）

印は「1〜3着が5頭の中に全部入る確率」が最も高くなる5頭に付ける（2026-11-17〜）。単勝オッズから見た勝率とSIMの勝率で各馬の勝率を作り直し、2着・3着は勝率を平らにして（ヘネリー式）2万回並べ、3着以内に入る回数の多い5頭を選ぶ。◎○▲＝その中の勝率上位3頭、△△＝残り2頭。`sim` の出力に「1〜3着が全部入る確率」と自信度（高・中・低）が出る。

検証（2026年・2,704レース、確定オッズ）：

| | 1〜3着が全部入る | 2頭以上入る |
|---|---|---|
| 5頭推奨（オッズ＋SIM） | 37.7% | 83.2% |
| 同・自信度「高」のレース（235） | 73.6% | — |
| 同・自信度「中」のレース（468） | 54.9% | — |
| 5頭推奨（SIMだけ。オッズなし） | 33.8% | 80.0% |
| 以前の印（SIMの勝率・複勝率順） | 33.8% | 80.3% |
| 人気上位5頭 | 37.2% | — |

1〜3着のうち6番人気以下の馬が1頭でも来るレースが約6割あり、5頭では全体の4割弱が上限に近い。
